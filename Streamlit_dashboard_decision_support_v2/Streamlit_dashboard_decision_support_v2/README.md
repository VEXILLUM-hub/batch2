# 배치 증류 이상신호 의사결정 지원 대시보드 v2

연구용 센서 이상탐지 결과를 Run 단위로 검토하고, 조사 우선순위를 제안하는 Streamlit 앱입니다.

## 실행

```bash
pip install -r requirements.txt
streamlit run app.py
```

Python 3.12를 권장합니다.

## 주요 변경

- 목표 오탐률과 연속 확인 Window를 PCA 관리한계, RF 확률 기준, 경보 구간 및 상태 판정에 연동
- 안정·주의·위험 상태와 조사 우선순위를 실제 계산값으로 생성하는 규칙 기반 의사결정 지원
- 상단 화면 전환 메뉴로 Run 판독, 모델 검증, 사전예측 검토, 현장 전환을 분리
- 흰색 표를 제거하고 다크 테마 기반 SOP·결과 표현으로 통일
- FDA Process Validation, ICH Q9(R1), ICH Q10, FDA 21 CFR Part 11 공식 근거 연결

## 사용 제한

본 앱은 연구 검증용입니다. 자동 공정제어, 일탈·OOS 확정, 배치 합격·불합격 또는 출하 판정에 사용할 수 없습니다.
